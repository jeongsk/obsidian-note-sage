# Quickstart: Agent Options

**Date**: 2025-12-28
**Feature**: Agent Options (001-agent-options)

## Overview

이 기능은 Claude Agent SDK의 고급 옵션들을 Note Sage 설정 UI를 통해 제어할 수 있게 합니다.

## 설정 옵션

### 1. 최대 턴 수 (Max Turns)

대화가 무한 루프에 빠지는 것을 방지합니다.

- **위치**: 설정 > Agent 옵션 > 최대 턴 수
- **범위**: 1 ~ 100 (0 = 무제한)
- **기본값**: 0 (무제한)

```
예시: 10으로 설정하면 10턴 후 자동으로 세션 종료
```

### 2. 최대 비용 한도 (Max Budget)

> ⚠️ **API 키 사용자 전용**: 이 옵션은 API 키가 설정된 경우에만 표시됩니다.

세션당 최대 API 비용을 제한합니다.

- **위치**: 설정 > Agent 옵션 > 최대 비용 한도
- **범위**: $0.01 ~ $100.00 (0 = 무제한)
- **기본값**: 0 (무제한)

```
예시: $1.00로 설정하면 비용이 $1에 도달할 때 세션 자동 종료
```

### 3. Extended Thinking

Claude가 복잡한 문제에 대해 더 깊이 생각하도록 합니다.

- **위치**: 설정 > Agent 옵션 > Extended Thinking
- **하위 옵션**: 최대 사고 토큰 수 (1,000 ~ 100,000)
- **기본값**: 비활성화

```
활성화하면 Claude의 응답에 사고 과정이 포함됩니다.
더 나은 품질의 응답을 얻을 수 있지만, 토큰 사용량이 증가합니다.
```

### 4. 권한 모드 (Permission Mode)

Claude의 파일 및 시스템 접근 권한을 설정합니다.

- **위치**: 설정 > Agent 옵션 > 권한 모드
- **옵션**:
  - `bypassPermissions` (기본값): 모든 권한 우회, 최대 편의성
  - `acceptEdits`: 파일 편집만 자동 승인
  - `default`: 모든 작업에 확인 필요
  - `plan`: 계획 모드 (실행 없이 계획만)

## 사용 예시

### 예시 1: 안전한 테스트 환경

```
최대 턴 수: 5
최대 비용: $0.50
권한 모드: default
```

짧은 대화로 테스트하고, 모든 작업에 확인을 요구합니다.

### 예시 2: 깊은 분석 모드

```
Extended Thinking: 활성화
최대 사고 토큰: 50,000
권한 모드: bypassPermissions
```

복잡한 코드 분석이나 문제 해결에 적합합니다.

### 예시 3: 비용 관리 모드 (API 키 사용자)

```
최대 비용: $5.00
최대 턴 수: 20
```

일일 사용량을 제한하여 예산을 관리합니다.

## 문제 해결

### Q: 비용 한도 설정이 보이지 않습니다

API 키가 설정되어 있는지 확인하세요. Claude Code 구독자는 월정액이므로 이 옵션이 표시되지 않습니다.

### Q: Extended Thinking을 활성화했는데 사고 과정이 보이지 않습니다

일부 모델에서만 Extended Thinking이 완전히 지원됩니다. Claude Opus 또는 최신 Sonnet 모델을 사용해보세요.

### Q: 설정을 변경했는데 적용되지 않습니다

설정 변경은 다음 세션부터 적용됩니다. 새 대화를 시작해보세요.
